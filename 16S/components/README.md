# 16S Analysis Components

Preliminary taxonomic analysis outputs from EMU species-level classification (pre-OTU-clustering).

## `basic/`

Sphingomonadaceae genus-level summaries across samples.

| File | Description |
|------|-------------|
| `sphingomonadaceae_genera_by_barcode.md` | Genus counts per barcode |
| `sphingomonadaceae_genus_by_barcode.tsv` | Genus abundance table (TSV) |
| `sphingomonadaceae_relative_abundance_by_barcode.md` | Relative abundance summary |
| `sphingomonadaceae_relative_abundance_by_barcode.tsv` | Relative abundance table (TSV) |
| `sphingomonadaceae_species_by_barcode.tsv` | Species-level breakdown |
| `sphingomonadaceae_tiers.md` | Evidence tier classification |
| `novosphingobium_species_by_barcode.tsv` | Novosphingobium species breakdown |

## `output/`

Preliminary phylum-level figures and summary data from EMU baseline analysis.

| File | Description |
|------|-------------|
| `emu_baseline_results.xlsx` | Alpha diversity, beta diversity, taxonomic richness (11 sheets) |
| `phylum_cohort_summary.csv` | Mean phylum abundance by cohort |
| `phylum_per_sample_data.csv` | Per-sample phylum abundance |
| `phylum_statistics.csv` | Phylum-level descriptive statistics |
| `phylum_composition_report.txt` | Text summary of phylum composition |
| `phylum_top3_stacked_per_sample.png` | Per-sample phylum stacked bar chart |
| `phylum_top3_cohort_mean_sd.png` | Cohort mean ± SD phylum comparison |
| `fig1_taxonomic_richness.png` | Genus/species richness by cohort |
| `fig2_alpha_diversity.png` | Alpha diversity indices by cohort |
| `fig3_beta_diversity_pcoa.png` | PCoA ordination |
| `fig4_prominent_taxa.png` | Top 15 genera and species |
